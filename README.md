## 🚀 How to Run Locally (लोकल में कैसे चलाएं)

### Option 1: One-Click Launcher (सबसे आसान)
1. `D:\Nexora_Global_Consulting\` फ़ोल्डर में जाएं।
2. `start-website.bat` फ़ाइल पर डबल-क्लिक करें।
3. यह तुरंत ब्राउज़र में `http://localhost:8080` खोल देगा!

### Option 2: Direct Open in Browser (सीधे ब्राउज़र में)
- सीधे `index.html` फ़ाइल पर डबल-क्लिक करके Chrome, Edge या Firefox में खोलें।
